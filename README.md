# Pocket Booth

A phone recorder for vocals over a beat, in one web page.

- Load any audio file as the beat, then record takes on as many vocal tracks as you want
- Delay calibration (clap test or tap test) so Bluetooth headphones don't put your vocals late
- Mic limiter matched to the Fruity Limiter in the KanKan record preset (+6 dB into a 0 dB ceiling)
- Per-take nudge, mute/solo/volume, pre-roll
- Export a WAV mix or vocal stems that start at 0:00 for FL Studio
- Saves on the phone automatically

Open `index.html` from an https:// address (the mic is blocked on file:// pages).
